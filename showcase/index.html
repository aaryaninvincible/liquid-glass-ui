🔍 How BeatWave's Liquid Glass Works

BeatWave achieves real-time liquid glass in Android using a 3-layer architecture:

1
Backdrop Pixel Capture (GraphicsLayer)

Using rememberLayerBackdrop() and Compose 1.7+ GraphicsLayer.record(), the underlying app screen content is rendered into an offscreen RenderNode.

2
Adaptive Resolution Downscaling

Glass is processed at glassResolutionScale (0.30x on high tier, down to 0.18x on low RAM devices). Heavy blur masks the downscaling, saving up to 85% GPU fill rate.

3
AGSL RuntimeShader Refraction Pipeline

Android 13+ (API 33) RuntimeShader evaluates a 2D Signed Distance Field (SDF) of the rounded rectangle, bends rays via circleMap, and disperses 7 light wavelengths.

4
Specular Rim Drift (Lighting Engine)

A drifting specular highlight vector oscillates over 7000ms, producing physical light glints on the pill edges rather than static borders.

📦 Compose Usage Example

// 1. Mark your screen background:
val backdrop = rememberLayerBackdrop()
Box(Modifier.layerBackdrop(backdrop)) {
    // Screen content (album art, lists, etc.)
}

// 2. Wrap your floating nav bar or player:
Box(
    modifier = Modifier
        .liquidGlass(
            backdrop = backdrop,
            config = GlassEffectConfig(
                vibrancy = 1.2f,
                blurRadiusDp = 24f,
                lensHeight = 0.4f,
                lensAmount = 0.6f,
                chromaticAberration = true
            ),
            shape = ContinuousRoundedRectangle(50)
        )
) {
    // Nav items or player controls
}
